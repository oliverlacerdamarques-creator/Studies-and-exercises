Principais formatações

Negrito / Destaque

Para deixar o texto em negrito, utilize a tag <strong>.

Itálico / Ênfase

Para deixar o texto em itálico, utilize a tag <em>.

Texto marcado

Para marcar um texto, utilize a tag <mark>.

Texto pequeno

Para deixar o texto em pequeno, utilize a tag <small>.

Texto deletado

Para deixar o texto em deletado, utilize a tag <del>.

Texto inserido

Para deixar o texto em inserido, utilize a tag <ins>.

Texto sobrescrito

Para deixar o texto em sobrescrito, x20+3, utilize a tag <sup>.

Texto subscrito

Para deixar o texto em subscrito, H2O, utilize a tag <sub>.
